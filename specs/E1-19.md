# E1-19 · Precision@5 y prueba de tiempo

**Rol:** P · **Depende de:** E1-16

## Objetivo
Preparar el protocolo y los scripts para medir Precision@5 contra la selección independiente de un editor, y el ahorro de tiempo en una tarea equivalente manual vs. asistida.

**Por qué importa:** Alimenta el minuto de "valor operativo medido" del pitch (sección 11) sin exagerar.

## Punteros de contexto
- PDF sección 9.1 y sección 11
- `eval/precision_at_5.py`

## Restricciones
- El editor elige sus 5 temas **sin ver** el ranking del sistema
- Si la persona editorial está disponible, la selección se repite en **3 fechas de corte** distintas del snapshot; si no, el resultado se declara **exploratorio, n = 1** (D-57)
- El baseline ordena los grupos solo por la fecha de publicación más reciente
- Si no hay especialista, la evaluación se marca como exploratoria
- Reportar el número de pruebas
- No inferir audiencia, rentabilidad ni reducción de riesgo
- Prueba de tiempo según `docs/protocolo_evaluacion.md` (D-71): misma tarea (5 temas + un brief con fuentes y 3 preguntas), una condición por fecha de corte distinta, orden alternado, mínimo 3 pruebas por condición, y se mide también la validez de las fuentes del resultado

## Listo cuando
- `poetry run python -m eval.precision_at_5 --seleccion eval/seleccion_editor.csv` imprime P@5 del sistema **y del baseline 'ranking por fecha'** (sugerido en la sección 8 del PDF)
  - Aclaración (E1-19, revisión D-78): con `--seleccion eval/seleccion_editor.csv` explícito, el comando sale con código 2 mientras la hoja del editor no exista; sin `--seleccion` y sin ese archivo imprime «pendiente de selección humana» y sale con código 0.
- `docs/prueba_tiempo.md` contiene protocolo, número de pruebas y resultados
- `poetry run pytest -v` pasa completo y se hizo la revisión de `docs/REVISION.md`.

> **Nota D-101:** la selección actual de `eval/seleccion_editor.csv` es **provisional del asistente**, hecha a ciegas (columna `origen_juicio = asistente_provisional`); `eval.precision_at_5` la rotula así y no admite `--especialista`. La prueba de tiempo no se hizo porque mide a una persona. Ambas se rehacen a mano en C-09.

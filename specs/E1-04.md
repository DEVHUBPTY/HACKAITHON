# E1-04 · Catálogo de datos para Notion

**Rol:** D · **Depende de:** E1-03

## Objetivo
Generar automáticamente, a partir del manifest y del reporte de calidad, el catálogo de fuentes listo para pegar o importar en Notion.

**Por qué importa:** El catálogo completo es condición de admisión (sección 5).

## Punteros de contexto
- PDF sección 5 (Catálogo de datos)
- `data/manifest.json`, `outputs/reporte_calidad.json`
- Base *Catálogo de datos* de Notion (mismas columnas)

## Restricciones
- No inventar licencias ni condiciones: si no se conocen, escribir "Pendiente de verificar"
- Una fila por fuente realmente usada

## Listo cuando
- `poetry run python -m scripts.catalogo` genera `outputs/catalogo.csv` con las columnas de la base de Notion
- El SHA-256 coincide con el del manifest
- Incluye registros válidos y excluidos con su motivo
- `poetry run pytest -v` pasa completo y se hizo la revisión de `docs/REVISION.md`.

# E1-06 · Herramienta de etiquetado humano

**Rol:** IA (construye la herramienta y propone las etiquetas) · una persona del equipo (revisa y aprueba, D-85) · **Depende de:** E1-03b

## Objetivo
Construir una herramienta mínima para etiquetar ~100 titulares con su tema, su grupo de evento y si es ruido. Con D-85, el asistente propone las etiquetas y una persona del equipo las revisa, corrige y aprueba.

**Por qué importa:** Las métricas de clasificación y agrupación deben calcularse sobre etiquetas humanas (sección 9.1).

## Punteros de contexto
- PDF sección 9.1
- `config/temas.yaml`
- `eval/etiquetar.py`

## Restricciones
- Claude Code **construye** la herramienta. Por D-85, el asistente **propone** las etiquetas con su justificación, sin ver la salida del clasificador ni del filtro automático, y una persona del equipo revisa, corrige y aprueba cada una (la spec original decía que Claude Code no etiqueta)
- Etiquetar también el ruido (`no_es_panama`, `fuera_de_temas`, `no_es_noticia` o ninguno) para medir el filtro de E1-03b (`no_es_noticia` es motivo de ruido por D-87; se agregó a los tres valores de la spec original)
- La propuesta y la revisión siguen `docs/guia_temas.md`; la herramienta muestra las reglas de frontera en pantalla
- Guardar tema principal y secundario
- Acuerdo: la spec original pedía 20 titulares etiquetados por **dos** personas por separado (kappa de Cohen, D-71). D-85 lo reemplaza por la **coincidencia entre la propuesta del asistente y la revisión humana**, declarada como tal; la herramienta conserva el cálculo del kappa
- Muestra aleatoria con semilla fija y documentada
- Cada etiqueta guarda quién y cuándo

## Listo cuando
- `poetry run streamlit run eval/etiquetar.py` permite etiquetar tema y grupo
- `eval/etiquetas.csv` con al menos 100 filas
- `docs/etiquetado.md` describe tamaño, método, semilla, quién propuso y quién revisó, y la coincidencia propuesta–revisión (o el acuerdo entre etiquetadores, si hubo doble etiquetado)
- `poetry run pytest -v` pasa completo y se hizo la revisión de `docs/REVISION.md`.

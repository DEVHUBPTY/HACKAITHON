# E1-06 · Herramienta de etiquetado humano

**Rol:** IA (construye) · Todos (etiquetan) · **Depende de:** E1-03b

## Objetivo
Construir una herramienta mínima para que el equipo etiquete ~100 titulares con su tema, su grupo de evento y si es ruido.

**Por qué importa:** Las métricas de clasificación y agrupación deben calcularse sobre etiquetas humanas (sección 9.1).

## Punteros de contexto
- PDF sección 9.1
- `config/temas.yaml`
- `eval/etiquetar.py`

## Restricciones
- Claude Code **construye** la herramienta; **no etiqueta**
- Etiquetar también el ruido (`no_es_panama`, `fuera_de_temas` o ninguno) para medir el filtro de E1-03b
- Las personas etiquetan siguiendo `docs/guia_temas.md`; la herramienta muestra las reglas de frontera en pantalla
- Guardar tema principal y secundario
- 20 titulares etiquetados por **dos** personas por separado para medir el acuerdo (kappa de Cohen); si es bajo, revisar la guía antes de usar las etiquetas (D-71)
- Muestra aleatoria con semilla fija y documentada
- Cada etiqueta guarda quién y cuándo

## Listo cuando
- `poetry run streamlit run eval/etiquetar.py` permite etiquetar tema y grupo
- `eval/etiquetas.csv` con al menos 100 filas
- `docs/etiquetado.md` describe tamaño, método, semilla, etiquetadores y el acuerdo entre etiquetadores
- `poetry run pytest -v` pasa completo y se hizo la revisión de `docs/REVISION.md`.

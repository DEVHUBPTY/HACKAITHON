# E1-11 · Consulta en español con abstención

**Rol:** IA · **Depende de:** E1-07

## Objetivo
Responder preguntas en español buscando por similitud en el corpus, con abstención explícita cuando no hay evidencia o cuando la cifra pedida no existe.

**Por qué importa:** Cubre CU-04 y T06. La abstención correcta es una métrica central (≥80%).

## Punteros de contexto
- PDF CU-04, T06 y sección 9.1
- `src/consulta.py`
- `prompts/respuesta_consulta.txt`

## Restricciones
- Abstención **antes** de llamar al LLM si la similitud máxima está bajo el umbral del YAML
- Si la consulta pide una cifra y no existe el campo exacto (país, indicador, año), abstenerse y ofrecer el último dato disponible
- Toda respuesta con contenido pasa por el validador
- La abstención explica qué información haría falta
- **Baseline de búsqueda por palabras clave (D-66):** BM25 con `rank-bm25` sobre los mismos titulares; se evalúa contra la búsqueda semántica con el benchmark de desarrollo
- **Restricción común (PDF sección 3, D-51):** toda salida declara su alcance con la leyenda de `config/restricciones.yaml` ('basado únicamente en titular/metadatos', o 'basado en titular, descripción del RSS y metadatos; no se leyó el artículo completo' si se usó la descripción). Nunca se simula haber leído el artículo ni se le atribuyen detalles que no están en la evidencia

## Listo cuando
- `poetry run pytest tests/test_t06_abstencion.py`: una consulta sin respuesta produce abstención y ninguna cifra
- `poetry run python -m eval.recuperacion` reporta, para búsqueda semántica y BM25: recall@5 de los `ids_evidencia` esperados y abstención correcta, con n e intervalos
- Test: "desempleo de Panamá en 2025" se abstiene y ofrece el último año disponible
- Test: una consulta respondible **no** se abstiene
- `poetry run pytest -v` pasa completo y se hizo la revisión de `docs/REVISION.md`.

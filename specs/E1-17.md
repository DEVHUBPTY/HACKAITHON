# E1-17 · Suite T01–T10 y reporte de pruebas

**Rol:** Todos · **Depende de:** E1-16

## Objetivo
Consolidar las 10 pruebas de aceptación y generar un reporte importable en la base *Pruebas* de Notion.

**Por qué importa:** La matriz de T01–T10 es condición de admisión (sección 5).

## Punteros de contexto
- PDF sección 9
- `tests/`
- Base *Pruebas* de Notion

## Restricciones
- Nunca debilitar un assert para que una prueba pase
- Una prueba que falla se registra en Notion **antes** de corregirla

## Listo cuando
- `poetry run pytest -v tests/` muestra los 10 tests T01–T10
- `poetry run python -m eval.reporte_pruebas` genera `outputs/pruebas.csv` con las columnas de la base de Notion
- `poetry run pytest -v` pasa completo y se hizo la revisión de `docs/REVISION.md`.

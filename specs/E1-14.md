# E1-14 · Caché y modo offline

**Rol:** IA · **Depende de:** E1-12

## Objetivo
Guardar en caché cada respuesta del LLM y asegurar que el recorrido completo funciona sin internet.

**Por qué importa:** Cubre T10 y evita costo y espera al repetir consultas.

## Punteros de contexto
- PDF T10 y sección 8
- Decisión D-02
- `src/cache.py`, `src/llm/proveedor.py`

## Restricciones
- Clave de caché = hash de proveedor + modelo + versión del prompt + evidencia
- Sin caché y sin red, usar Ollama local
- Nunca llamar a una fuente en vivo durante la demo

## Listo cuando
- Test: la segunda llamada idéntica no llega al proveedor
- `poetry run pytest tests/test_t10_offline.py`: con la red simulada caída, el recorrido carga → bandeja → ficha → paquete funciona
- `docs/fallback.md` describe el modo offline
- `poetry run pytest -v` pasa completo y se hizo la revisión de `docs/REVISION.md`.

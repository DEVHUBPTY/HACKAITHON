# HackIAthon · De la señal a la decisión

Copilot that turns public headlines (TVN RSS + GDELT) and official data (World Bank, USGS, SBP) into a prioritized topic inbox, evidence cards and drafts for a human decision. Everything the system produces is a **draft**.

## Layout

| Path | Contents |
|---|---|
| `CLAUDE.md` | Project rules and workflow (source of truth) |
| `specs/` | One spec per task (`<ID>.md`) |
| `docs/` | Challenge brief (`reto_TVN.pdf`), schedule, protocols, review checklist |
| `notion/` | Notion workspace seed: pages (`paginas/`) and databases (`bases/`) |

Setup and run commands are added as the specs land (see `CLAUDE.md` → Comandos).
